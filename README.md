# Shivam Upadhyay — Portfolio

Black-and-gold portfolio built with Next.js (App Router) and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import the repo at vercel.com/new. No configuration needed.

## Customize

The accent colour is the `--accent` variable in `app/globals.css` (`.pg`). Sections live in `components/`.
